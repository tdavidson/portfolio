# Roadmap

What's coming next for Portfolio, and what shipped recently. Every change is in the
[CHANGELOG](./CHANGELOG.md); releases are on [GitHub](https://github.com/tdavidson/portfolio/releases).
Ideas and requests are welcome in [Discussions](https://github.com/tdavidson/portfolio/discussions)
or [Issues](https://github.com/tdavidson/portfolio/issues), and [sponsors'](https://github.com/sponsors/tdavidson)
requests are weighed first.

## In progress

| What | Why it matters |
| --- | --- |
| **Statement review** | Check a quarter's LP statements against the books before they go out, with per-vehicle instructions, watched accounts and known adjustments, and a sign-off. |
| **Easier upgrades** | One command that pulls the latest release and lists the database migrations a self-hosted install still needs, with their SQL. |
| **Connect any assistant in a minute** | Copy-ready steps for Claude, ChatGPT, Claude Code, Codex, Cursor and VS Code, filled in with your own address. |

## Next

| What | Why it matters |
| --- | --- |
| **Custom view forms with approval** | Let a view collect input (a mark, a note, a request) that waits for an admin's approval before it touches the books. |
| **Checked skills** | Evaluations for the LP letter and memo skills, so a change to a prompt is tested before it ships. |
| **A fund-ops skill for any agent** | A skill that helps with fund operations questions even before Portfolio is installed. |
